## Hello,

I am a KSP, Minecraft, KSA, and (somewhat of a) Factorio modder. I'm also a GregTech: New Horizons contributor.

I know languages like:

- Python 3 (best)
- C#
- GDScript (for Godot)
- HTML and JavaScript (for websites)
- C++ (basics)
- Java (basics, mostly for Minecraft mods)

I have a [discord server](https://discord.gg/qgdEU2X6Xj) for my mods and a YouTube channel at https://www.youtube.com/@chitak985.

### Projects
Here are some of my projects:

- [Sophisticated Interstellar Flight Simulator](https://github.com/Chitak985/sophisticated-interstellar-fight-simulator): A multiplayer space simulator game written in Godot. I also have a [discord server](https://discord.gg/rYBtCaUXm7) for it.
- [GregTech Old Edition](https://github.com/Chitak985/GregTechOldEdition): A GregTech-like modpack as a Java agent to use with the first Minecraft version, rd-132211.
- [GT:NH Multiblocks](https://gtnhmultiblocks.pythonanywhere.com/): Website for the Minecraft modpack GregTech: New Horizons, it lets a user emulate multiblock construction, calculate required resources, and see multiblock parameters. Written with Flask data insertion, JavaScript frontend and calculation, and HTML for the website. Also has a somewhat [outdated repository](https://github.com/Chitak985/gtnh-multiblocks).
- [Ad Astra PromisedWorlds](https://github.com/Chitak985/ad-astra-PromisedWorlds): Adds the KSP planet mod Promised Worlds to KSP. Mostly finished but not worked on anymore.
- [Beantorio (Factorio Mod)](https://github.com/Chitak985/beantorio): A Factorio mod that adds BEANS. Also my only Factorio mod as of now.
- KSA mods:
  - KSA Extreme Editor (no repository yet): An in-game editor that can edit anything that is possible to edit, also the only KSA mod I work on nowadays.
  - [KittenPatcher](https://github.com/Chitak985/KittenPatcher): An XML patching mod for KSA that became inferior to another after 18 hours. Never finished nor is it a really good mod.
  - [KSAMiscParts](https://github.com/Chitak985/KSAMiscParts): A simple KSA mod adding some miscellaneous parts like a launch escape system and structural beams.
- KSP mods:
  - [Khemistry](https://github.com/Chitak985/khemistry): My biggest and best KSP mod, it makes the game as realistic as possible and as a result, extremely complicated and hard. Has a total of more than 5000 lines of C# code, a dozen part modules, and thousands of resources!
  - [RealGalacticSystems](https://github.com/Chitak985/ksp-real-galactic-systems): Adds the entire real universe (except our Solar System) to the game. Rather incomplete and buggy, however.
  - [GalacticDisk](https://github.com/Chitak985/GalacticDisk): Adds highly configurable galactic disks with no dependencies. My most popular mod as of now.
  - [Almajara-Continued](https://github.com/Chitak985/Almajara-Continued): A continuation of the mod Almajara: A Galactic Adventure with many bugfixes and adjustments.
  - [ResourcefulTechnologies](https://github.com/Chitak985/ResourcefulTechnologies): Adds various ISRU inspired by KSPIE ISRUs, but in a more modern style like FarFutureTechnologies.
  - [ConfigMusic](https://github.com/Chitak985/config-ksp-music): Adds music to celestial bodies and/or their biomes using configs.
  - [Pulsaris Galaxy](https://github.com/Chitak985/pulsaris-galaxy): Adds a large galaxy with hundreds of custom, hand-made bodies. Largely unfinished.
  - [MassRingAdder](https://github.com/Chitak985/mass-ring-adder): Procedurally adds rings to every single loaded body using just ModuleManager patches. Also highly configurable and adds simple ways to add rings.
  - [Chitak's Outer Planets](https://github.com/Chitak985/chitaks-outer-planets): My own outer planets for KSP. Not finished but the main gas giants are there and have an okay texture.
  - [Chitak's Weird Planet Pack](https://github.com/Chitak985/chitaks-weird-planet-pack): A planet pack consisting of the weirdest planets possible.
  - [RingMassAdder](https://github.com/Chitak985/RingMassAdder): Adds the weight of a ring to its body's mass. Done in 10 seconds and not tested.
